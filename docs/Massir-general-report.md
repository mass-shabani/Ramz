### 📋 گزارش مرجع پروژه Massir

Massir یک **فریم‌ورک برنامه‌نویسی ماژولار برای پایتون** است که با هدف ساخت اپلیکیشن‌های مقیاس‌پذیر و قابل نگهداری بر پایه معماری پلاگین‌محور (Plugin-based) طراحی شده است.

#### 🎯 فلسفه و اهداف اصلی
فلسفه اصلی Massir بر **ماژولاریتی** استوار است. هدف این فریم‌ورک شکستن پروژه‌های پیچیده به اجزای کوچک و مستقل است تا توسعه‌دهندگان بتوانند بدون نگرانی از تأثیر تغییرات روی سایر بخش‌ها، ماژول‌های خود را به صورت موازی توسعه دهند. مزایای کلیدی این رویکرد عبارتند از:
*   **جداسازی دغدغه‌ها**: هر ماژول مسئول یک جنبه خاص از برنامه است.
*   **ترکیب انعطاف‌پذیر**: اپلیکیشن‌ها از ترکیب ماژول‌های قابل تعویض ساخته می‌شوند.
*   **نگهداری آسان**: تغییرات در یک ماژول تأثیری بر سایرین ندارد.
*   **تست مستقل**: ماژول‌ها به صورت مجزا قابل تست هستند.

#### ⚙️ اجزای اصلی هسته (Core)
هسته فریم‌ورک شامل اجزای کلیدی زیر است که در پوشه `massir/core/` قرار دارند:

| جزء | فایل | توضیح |
|---|---|---|
| **App** | `app.py` | ارکستراتور مرکزی که چرخه حیات کل اپلیکیشن را مدیریت می‌کند. |
| **IModule و ModuleContext** | `interfaces.py` | واسط‌های اصلی برای ساخت ماژول‌ها. |
| **Hook و HooksManager** | `hooks.py` | سیستم رویدادمحور با پشتیبانی از قلاب‌های سیستمی و سفارشی. |
| **RunOrderGroupManager** | `run_order_group.py` | مدیریت گروه‌های اجرایی و زمان‌بندی ماژول‌ها بر اساس تریگرها. |
| **ModuleRegistry** | `registry.py` | رجیستری سرویس‌ها برای مدیریت وابستگی‌ها. |
| **SettingsManager** | `settings_manager.py` | مدیریت تنظیمات با اولویت چهارسطحی (ماژول → کد → JSON → پیش‌فرض). |
| **ModuleLoader** | `module_loader.py` | بارگذاری ماژول‌ها و بررسی نیازمندی‌ها. |

#### 🧩 ماژول‌های سیستمی داخلی
پروژه Massir شامل مجموعه‌ای از ماژول‌های آماده و پیش‌فرض است که در پوشه `massir/modules/` قرار گرفته‌اند:

| ماژول | توضیح |
|---|---|
| `network_fastapi` | پشتیبانی از وب و API با FastAPI. |
| `network_socket` | ارتباطات مبتنی بر سوکت خام. |
| `network_ssl` | ارتباطات امن با استفاده از SSL/TLS. |
| `network_websocket` | پشتیبانی از WebSocket برای ارتباطات بلادرنگ. |
| `system_database` | واسط یکپارچه برای دیتابیس‌های رابطه‌ای (PostgreSQL, MySQL, SQLite). |
| `system_encryption` | قابلیت‌های رمزنگاری و امنیتی. |
| `system_logger` | سیستم لاگ‌گیری پیشرفته. |
| `system_network` | مدیریت شبکه سطح بالا. |

#### 🔌 نمونه‌های کاربردی (Examples)
پروژه شامل نمونه‌های عملی متعددی است که کاربردهای مختلف فریم‌ورک را نشان می‌دهند:
*   **basic_app_consumer**: ساده‌ترین اپلیکیشن برای شروع.
*   **basic_website_example**: وب‌سایت ساده با موتور تمپلیت Jinja2.
*   **database_example**: پیاده‌سازی کامل CRUD، تراکنش‌ها، و کوئری‌های خام.
*   **encryption_example**: نمایش قابلیت‌های رمزنگاری.
*   **network_nodes_test_example**: تست ارتباط بین نودهای شبکه.
*   **socket_example** و **ssl_example**: نمونه‌های ارتباط سوکت امن.
*   **web_api_example**: پیاده‌سازی API وب.

#### 🧪 تست و اعتبارسنجی

#### 🚀 ویژگی‌های کلیدی فریم‌ورک
بر اساس README پروژه، Massir از ویژگی‌های زیر پشتیبانی می‌کند:
*   **Run Order Groups**: سازماندهی ماژول‌ها در گروه‌های اجرایی با زمان‌بندی مبتنی بر تریگر.
*   **Dynamic Run-At System**: اجرای گروه‌های ماژول در نقاط مشخصی از چرخه حیات.
*   **Module Lifecycle Hooks**: سیستم رویدادمحور قابل توسعه.
*   **Dependency Resolution**: مرتب‌سازی و اعتبارسنجی خودکار وابستگی‌های ماژول.
*   **Multi-Transport Networking**: پشتیبانی از Socket، WebSocket، SSL و FastAPI.
*   **Configuration Management**: سیستم اولویت‌بندی چهارسطحی برای تنظیمات.
*   **Hot Reload**: قابلیت ری‌استارت اپلیکیشن در زمان اجرا.
*   **Async Core**: مبتنی بر `asyncio` برای I/O با کارایی بالا.
*   **Simple Module Interface**: تنها پیاده‌سازی متدهای `start()` و `stop()` الزامی است.
